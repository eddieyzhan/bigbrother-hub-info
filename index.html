BigBrother Mac Hub

A private, self-hosted personal assistant hub. It connects accounts chosen by its operator, retains useful records on the operator's Mac, and provides tools for search, recall and explicitly requested actions.

The Gmail connector keeps authorized mailboxes up to date using an IMAP IDLE connection and the Gmail API. It reads message content, headers, labels and attachment metadata. Initial setup does not import historical mail. Gmail's IMAP OAuth permission includes sending and deletion, but the current Gmail connector only reads.

Account connections, retained data and optional AI assistance are controlled by the operator. This is a personal-use application, not a public hosted service. This public website contains only application information; it does not host the hub, accept account credentials or display messages.
